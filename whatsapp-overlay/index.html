Chrome Extension · Persönlicher Gebrauch

WhatsApp Overlay Assistant

On-demand Antwort-/Ton-Vorschläge für WhatsApp Web. Liest den sichtbaren Chat nur, wenn du aktiv auf den Vorschlag-Button klickst — kein Dauer-Scraping, kein Auto-Send.

WhatsApp ToS untersagen automatisiertes Auslesen von Chats über inoffizielle Wege, auch beim eigenen Account. Dieses Tool ist für den persönlichen Gebrauch bei niedrigem Volumen gedacht, nicht im Chrome Web Store veröffentlicht, und nicht für andere Nutzer bestimmt.
Extension herunterladen (.zip)

Installation (unpacked)

  1. ZIP entpacken
  2. chrome://extensions öffnen, Entwicklermodus aktivieren
  3. „Entpackte Erweiterung laden" → entpackten Ordner wählen
  4. Extension-Icon anklicken, Claude API Key hinterlegen
  5. Auf web.whatsapp.com den grünen Kreis unten rechts nutzen
