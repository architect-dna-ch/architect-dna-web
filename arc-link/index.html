Your tablet is your laptop's keyboard.

Cracked laptop screen? Don't throw it out, and don't buy a tablet keyboard case. Plug the tablet into the laptop with one USB cable — and type and point on the tablet using the laptop's own keyboard and trackpad. No root, nothing to install on the tablet.

How it works

Laptop (keyboard + trackpad) ──USB──► Tablet (Android) arclink.py adb `input` → keys, taps, swipes

A tiny Python script on the laptop reads its own keyboard and trackpad, and feeds the keystrokes and gestures straight to the tablet over the USB debug bridge. The tablet needs no app — it just receives the input. Built for a MacBook + a Xiaomi Pad; works with any Mac/Linux laptop and any Android tablet.

Set it up in 5 minutes

  1. On the tablet: Settings → About → tap Build number 7× to unlock Developer options → turn on USB debugging. Plug into the laptop with a data cable and tap Allow.
  2. On the laptop: 
    cd arc-link
./setup.sh
    It installs adb + pynput if missing, then starts.
  3. First run (macOS): grant Accessibility and Input Monitoring in System Settings → Privacy & Security, so it can read your keyboard and trackpad.
While running: F10 toggles forwarding · F1 back · F2 home · F3 recents. Everything else types/points onto the tablet. Ctrl-C to quit.

Honest limits

  • The cursor is a virtual pointer (placed taps/drags, no true hover) — great for typing and navigating, approximate for fast dragging.
  • Keyboard chords (⌘C, ⌘-Tab…) are limited; plain typing + the mapped keys are solid.
  • A low-latency v2 (an on-device server) lives in server/ for when you want silky input.
