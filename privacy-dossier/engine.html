Neue Anfrage

Diese Seite läuft vollständig lokal in deinem Browser — kein Backend, keine Cookies, kein Tracking, keine Drittanbieter-Skripte. „Senden" öffnet dein eigenes E-Mail-Programm (mailto:) mit vorausgefülltem Text; nichts wird an einen Server dieser Seite übermittelt. Beim Senden wird die Anfrage automatisch im Dashboard erfasst (30-Tage-Frist), gespeichert nur in deinem Browser (localStorage).
